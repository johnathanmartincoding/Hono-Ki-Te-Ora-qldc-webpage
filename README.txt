Let me explain how to manage most of this —- most was vibe coded. 
In the file “central-lakes-directory.html” there is a list of resources that pull from the file “DATA.json.
To add, remove or change a resource, you just edit that file. 
All the links redirect to our GitHub pages version as you might have noticed.
There is a script “links-mode.js” that, when the “serve.py” is present, will change links to the GitHub repo. 
The “serve.py” is what we used to test the file locally on our computer, so we could check from different devices and etc.
For you, it probably isn’t necessary. 
I haven’t tested it, but deleting that file “serve.py” will change “link-mode.py”’s behaviour and change links to the live hkto website. 
There are some gaps in the website —- missing images, maybe a small bug or typo or sm, etc.
